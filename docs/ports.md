# Ports

This page lists ports of open-oscar-client-kit to other languages. The authors of each port write and maintain it. Each port on this page links a CI run that shows it passing the [suite](porting/suite.md). A listed port follows the [naming rule](porting/overview.md).

## Listed ports

None yet.

## Getting a port listed

1. Add the suite to the port's CI, as [the suite page](porting/suite.md) shows.
2. Pin the suite to one version, such as `open-oscar-client-kit@0.1.1`.
3. Run CI until every scenario passes.
4. Open an issue at [ukozi/open-oscar-client-kit](https://github.com/ukozi/open-oscar-client-kit/issues).
5. Put the link to the passing run in the issue.
6. Give the port's language, its repository and the suite version.
